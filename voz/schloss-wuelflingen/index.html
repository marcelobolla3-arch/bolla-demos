Persönliche Demo

Telefon-Assistent für das Restaurant Schloss Wülflingen

Hier können Sie direkt mit dem digitalen Telefon-Assistenten sprechen, den wir als Beispiel für das Restaurant Schloss Wülflingen vorbereitet haben. Er nimmt Anfragen entgegen, beantwortet häufige Fragen und notiert die Angaben für das Team.

So funktioniert es

Klicken Sie unten rechts auf «Gespräch starten» und erlauben Sie den Zugriff auf das Mikrofon. Sprechen Sie dann ganz normal, wie am Telefon. Mit «Beenden» schliessen Sie das Gespräch.

Zum Ausprobieren

  • Einen Tisch für Samstagabend reservieren
  • Eine Hochzeit oder ein Firmenfest anfragen
  • Nach Öffnungszeiten, warmer Küche oder Anreise fragen
  • Einen Seminarraum für einen halben Tag anfragen

Dies ist eine Demo: Es werden keine echten Reservationen oder Buchungen ausgelöst.
