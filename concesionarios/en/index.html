Assistant for a car dealership

This is how an assistant would reply in chat: stock of a generic segment, a test drive, the workshop, financing, hours, and a handoff to a person.

An illustrative example of how the assistant replies. It is a fixed script, not a real artificial intelligence. It does not book, it does not store what you type, and it is not the website of a specific dealership.

This page does not start a call. If the form shows a number, 000 000 000 is an example number and not a real one.

How to try the example

  1. Read the notice: the replies are already written.
  2. Choose a question or type your own.
  3. The text you type is not sent to the counter or to any server.
  4. The note on the right stays in the browser.
