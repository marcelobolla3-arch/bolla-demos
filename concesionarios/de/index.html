Assistent für ein Autohaus

So würde ein Assistent im Chat antworten: Bestand einer allgemeinen Fahrzeugart, Probefahrt, Werkstatt, Finanzierung, Öffnungszeiten und die Weitergabe an eine Person.

Ein anschauliches Beispiel dafür, wie der Assistent antwortet. Es ist ein festes Skript, keine echte künstliche Intelligenz. Es reserviert nicht, speichert nicht, was Sie schreiben, und ist nicht die Website eines bestimmten Autohauses.

Diese Seite startet keinen Anruf. Wenn im Formular eine Nummer steht, ist 000 000 000 eine Beispielnummer und keine echte.

So prüfen Sie das Beispiel

  1. Lesen Sie den Hinweis: die Antworten sind schon geschrieben.
  2. Wählen Sie eine Frage oder schreiben Sie eine eigene.
  3. Der geschriebene Text geht nicht an den Zähler und nicht an einen Server.
  4. Die Notiz rechts bleibt im Browser.
